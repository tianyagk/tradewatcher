# tradewatcher · 综合盯盘助手（Edge / Chromium 扩展）

一个把「行情 + 自选 + 持仓账本 + 板块资金 + 涨跌停复盘 + 财经日历 + 价格预警」做在一个侧边栏里的浏览器扩展。

数据全部来自**免费公开接口的延迟行情**（非 Level-2），仅作盯盘参考，**不构成投资建议**。

- 数据模型与持仓核算方式参考 **dsh-tradewatcher**（DeepSeek Harness 插件）
- 界面组织思路参考浏览器插件 **爱盯盘 / 52etf.site**
- 在此之上扩展了：多源兜底与 last-known-good 回填、板块资金流、涨跌停/炸板池复盘、市场宽度、多周期 K 线指标、沪深港通、价格预警与通知、数据导入导出

## 一、安装（Edge 开发者模式加载）

1. 打开 Edge，地址栏输入 `edge://extensions/` 回车
2. 打开左下角 **「开发人员模式」**
3. 点击 **「加载解压缩的扩展」**，选择本目录 `tradewatcher/`（含 `manifest.json` 的那一层）
4. 首次安装会自动打开设置页；工具栏出现 tradewatcher 图标

> 需要 Chromium 114+（侧边栏 API）。Edge 稳定版均满足。
> Chrome 同理：`chrome://extensions/` → 开发者模式 → 加载已解压的扩展程序。

**日常使用**

| 操作 | 位置 |
| --- | --- |
| 快速看行情 | 点击工具栏图标（弹窗，默认快捷键 `Alt+Shift+T`） |
| 完整盯盘面板 | 弹窗右上角 **▤** → 打开侧边栏；或右键扩展图标 → 打开盯盘面板 |
| 改设置 | 扩展详情页 → 扩展选项；或面板右上角 **⚙** |
| 固定侧边栏 | Edge 侧边栏面板右上角「图钉」 |

## 二、功能总览

### 弹窗（392 × 566）
- **核心指数条**：上证 / 深成 / 创业板 / 科创50 / 沪深300 / 中证500，点击进入完整面板
- **三个视图**：自选（缩略分时 + 涨跌幅）、持仓（总市值 / 当日盈亏 / 浮动盈亏 + 逐只当日盈亏）、大盘（涨跌家数条 + 涨停跌停家数 + 两市成交额）
- 时钟 + 交易状态（交易中 / 午间休市 / 集合竞价 / 已收盘）

### 侧边栏完整面板
- **顶部行情条**：A股指数 / 中国香港·亚太 / 欧美市场 / 大宗商品 四组（可在设置里勾选显示哪些组，可折叠）
  - 鼠标悬停 → **分时悬浮卡**（主图 + 昨收基准虚线 + 成交额）
- **九个页签**：

| 页签 | 内容 |
| --- | --- |
| 概览 | 核心指数、**涨跌分布**（涨跌趋势 / 成交量 / 全市场涨跌幅 11 档分布图）、持仓汇总、行业领涨领跌、自选速览 |
| 自选 | 分组管理（新建 / 改名 / 归档 / 恢复）、搜索添加、**行业板块名 + 板块涨幅 + 相对 alpha**、缩略分时、点击开抽屉 |
| 持仓 | 账户分组、**摊薄 / 均价双成本口径**切换、总市值 / 当日盈亏 / 浮动盈亏 / 累计已实现、买入 / 卖出 / 调整 / 编辑 / 移除、流水明细 |
| 大盘 | 六大指数、市场宽度、涨跌停统计、**内嵌大盘云图**（52etf.site 热力图）、个股检索 |
| 板块 | 行业 / 概念 / ETF 三类，按涨幅 / 主力净额 / 成交额排序，含领涨股与主力净额 |
| 资金 | 沪深港通（南向实时、北向已停止实时披露）、行业 / 概念板块主力净流入 TOP、个股主力净流入 TOP、个股资金流查询 |
| 涨停 | 涨停池 / 跌停池 / 炸板池；情绪温度（涨停数 / 跌停数 / **炸板率** / 最高连板）、连板数、封板时间、封单额、所属行业 |
| 日历 | 月历网格（**重要度三色**）+ 当日事件详情 + 手动增删 + 自动同步 |
| 预警 | 规则 CRUD、启用开关、触发历史 |

### 详情抽屉（右侧滑出）
- 固定信息头：名称 / 代码 / 市场 / 现价 / 涨跌幅 / 涨跌额
- 关键数据：今开、昨收、最高、最低、成交量、成交额、换手率、量比、市盈率、市净率、总市值、流通市值
- 图表页签：**分时 / 五日 / 日K / 周K / 月K / 年K**
  - 分时：价格线 + 均价线 + 昨收基准虚线 + 成交量 + 十字光标（时间 / 价格 / 涨跌幅 / 均价 / 量 / 额）
  - 五日：5 个交易日连续拼接（午休与隔夜已折叠），前复权口径按 5 分钟 K 线
  - K 线：蜡烛 + **MA5/10/20/60**（附当前值图例）+ **VOL** + **MACD(12,26,9)**（HIST 柱 + DIF/DEA 线）
  - 交互：**滚轮以光标为中心缩放**、**拖拽平移**、近 1 月 / 3 月 / 6 月 / 1 年 / 全部 快捷区间
  - 图上按持仓流水标注 **B/S 买卖点**
- 当日资金流：主力 / 超大单 / 大单 / 中单 / 小单净额
- 快捷操作：★ 加自选、＋ 加持仓、🔔 建预警

### 价格预警
- 按 **涨跌幅 %** 或 **现价** 设置 `≥ / ≤` 阈值
- 后台 Service Worker 每分钟检查（浏览器运行中即可），触发后推送**系统通知**
- 冷却时间去重（默认 10 分钟），避免反复打扰
- 工具栏**角标**可显示：大盘指数 / 自选首只 / 持仓当日收益率（红涨绿跌着色）

### 外观与隐私
- 主题：跟随系统 / 浅色 / 深色
- 配色：**红涨绿跌**（A 股习惯）可切换为绿涨红跌
- **极简 / 隐蔽模式**：整体去色，只保留强弱对比
- **不透明度**（40%–100%）与 **背景虚化**（毛玻璃）—— 上班摸鱼友好

> 兜底源在实际不可用时自动接管，界面会标注「数据源：新浪（已降级）」，不会出现空白或报错。
>
> **宏观模块的降级行为**：「涨跌分布」需全市场快照，东财 `push2` 被限流时会整块提示「涨跌幅分布需要全市场快照，上游繁忙时自动跳过」，而**不会**用残缺分页凑出一张失真的图；「成交量」走腾讯 `day/query`，与 `push2` 相互独立，因此即使 `push2` 不可用也能正常显示。


**可靠性设计**（都会有限流，所以做了这些）
- 所有上游请求：**3 轮 × 每主机 2 次重试 + 抖动退避 + 12 秒总截止**
- 三条独立数据链路，任一链路被限流时自动切换到兜底源
- TTL 缓存真正命中（写 + 读），并对相同请求做 inflight 去重
- **last-known-good**：某只标的某一刻缺价时用最近一次有效读数做字段级回填，价格不会在「数字 / —」之间闪烁（快照存 `chrome.storage.session`，SW 重启后仍生效）
- K 线历史按 `(secid, 周期)` 落盘缓存：首次拉全量、之后只增量合并，上游不可用时直接回退缓存并在图上标注
- 界面低频轮询（默认 10s，可调 3–120s）；后台只用 1 分钟的 alarms 做角标与预警，避免把 SW 撑爆

## 四、持仓账本口径

数量与成本**不落盘**，全部由 append-only 流水推导。

- **均价口径**：买入移动加权均价（含买入费用），卖出不改成本
- **摊薄口径（默认，与多数券商 App 一致）**：`摊薄成本 = (累计买入含费 − 累计卖出净额) ÷ 剩余数量`
- **恒等式**：`摊薄持仓盈亏 = 均价浮动盈亏 + 累计已实现`
- **当日盈亏** = 隔夜持仓 `(现价 − 昨收) × 隔夜数量` + 当日买入 `(现价 − 买入价) × 数量` + 当日卖出 `(卖出价 − 昨收) × 数量` − 当日费用
- 盈亏率：浮动盈亏率 = 浮动盈亏 ÷（成本 × 数量）；当日盈亏率 = 当日盈亏 ÷（隔夜数量 × 昨收 + 当日买入金额）
- 删除分组 = 归档（保留持仓与全部流水）；「移除持仓」要求数量为 0（先卖后移），保证流水完整可追溯
- 流水动词：`buy` 买入 / `sell` 卖出 / `adjust` 调整（送转股、纠错）/ `add` 新建持仓 / `remove` 移除 / `gcreate|grename|gdelete|grestore` 分组 / `pnote` 备注

> 跨市场标的盈亏按接口币种金额展示，**未做汇率折算**（人民币资产无影响）。

## 六、开发与验证

无构建链，源码即产物：改完直接在扩展管理页点「重新加载」即可。

**涨跌分布模块的独立预览页**（`tools/preview-distribution.html`）
模块用到的 CSS 变量与 SVG 渲染不易在扩展里反复试错，故提供独立预览页：

```bash
# 在仓库根目录起一个静态服务（ES module 需要 http 源，file:// 会被 CORS 拦）
python -m http.server 8791 --bind 127.0.0.1
# 浏览器打开
http://127.0.0.1:8791/tools/preview-distribution.html
```

页面内可切换**深/浅主题**与**红涨绿跌反转**，并内置降级态、空数据、极端偏态、全平盘、单档等边界用例。预览页内嵌的是 2026-09-24 的真实成交额快照与一组仿真分档数据。

**容易踩的坑（已在代码里注释）**
- `s()`（SVG 元素构造）走的是 `setAttribute`，`style` 必须传**字符串**；传对象会被序列化成 `"[object Object]"` 而失效，导致 SVG 失去宽高。`h()`（HTML 元素）才支持对象形式的 `style`
- 面板是 `height:100vh; overflow:hidden` 的 flex 列容器，子项**默认会被压缩**。新增顶栏区块时若不加 `flex: 0 0 auto`，行情条展开时会把它挤成 0 高度而「消失」
- 行情条网格不要用「`gap` + 透出底色」画边框：标的数不满一行时残余网格单元会显示成灰块

## 七、已知边界

- 全部为**延迟行情**（非 L2），盘中偶有缺口；国际指数与商品按源时区展示
- 上游对高频访问会限流甚至短暂封 IP；扩展已做缓存与退避，但仍可能出现短暂无数据，稍后自动恢复
- **东财 `push2*` 主机族**是板块榜 / 个股资金流 / 全市场涨跌幅分布的主源。若该主机族被限流（表现为连接被立即重置），扩展会自动切到新浪与东财 `datacenter` 兜底，界面会标注「已降级」；降级期间板块榜无「成交额」、个股资金流为日频口径，**涨跌幅分布图整块跳过**（宁可不画，也不用残缺分页凑一张失真的图）
- **北向资金**自 2024-08 起已停止盘中实时披露，面板会标注「已停止实时披露」；南向（港股通）仍展示
- **涨跌家数**依赖行情接口返回的涨跌统计字段（`f104/f105/f106`），该字段仅主源提供且易受限流影响。涨跌分布模块**优先用全市场快照自行统计**，快照不可用时才回退该字段；两者皆缺时面板提示「稍后自动重试」
- **两市成交额**与「较昨日变动」刻意使用同一单位（如 `1.65万亿` / `-0.11万亿`），避免不同量级并排时无法直观比较
- 财经日历自动源**不含美国 CPI（BLS）**、不含未上市公司 IPO 传闻 —— 这类日程请用「日历 → ＋事件」手动补录；财报预约披露与分红除权只针对**自选/持仓标的**同步
- 云图为第三方页面（52etf.site）内嵌；若对方调整页头策略导致无法内嵌，面板会提示，可用「新窗口」按钮打开
- 期货主连「昨收/昨结」等口径字段随接口语义展示，若做精确结算对账请以结算单为准
